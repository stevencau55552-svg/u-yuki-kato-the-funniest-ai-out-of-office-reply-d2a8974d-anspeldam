A program that writes a single-line out-of-office auto-reply (under 160
characters) in the voice of an AI agent heading off on vacation, to
`/output/entry.txt`.

Run it with Node 22:

```sh
node main.ts
```

Deterministic: one fixed line, no network, no randomness, stdlib only.
